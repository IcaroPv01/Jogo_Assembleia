# Assembleia

Jogo de tabuleiro de negociação diplomática estilo simulação ONU (SimulaRI+, PUCRS). Ensino médio, 5 jogadores, 30–45 min.

- `ferramentas/`: gerador de cartas (JSON → PNG/SVG) e PDF de impressão. Veja o README lá.
- Site de teste (GitHub Pages): galeria das cartas, atualizada a cada push na `main`.
